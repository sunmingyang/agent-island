# Roadmap

What's planned for Agent Island. Dates are intentions, not promises — the
tool stays small and reliable first.

## Now
- **Windows companion** — first public build (in final testing)
- Official homebrew-cask submission (at the 75-star notability bar)
- Release notes surfaced in-app via Sparkle (in CI as of 1.4.1)

## Next
- **iOS companion** — Live Activity / Dynamic Island status (scaffold exists)
- Raycast companion extension — quick usage/status check from the launcher
- Per-thread alarm queue improvements (multiple finished turns per provider)
- More UI languages — contributions welcome (see issues)

## Later
- Setapp distribution
- Deeper multi-agent support beyond Claude Code / Codex
